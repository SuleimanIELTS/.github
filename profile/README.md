## 🌟 Təşkilatın Missiyası (Organization Mission)

**Suleiman IELTS** — Cambridge IELTS Academic imtahanlarına (xüsusilə **Cambridge 15–21**) hazırlaşanlar üçün nəzərdə tutulmuş, heç bir diqqət yayındırıcı reklam, abunəlik xəbərdarlığı və ya interfeys qarışıqlığı olmayan ("distraction-free") minimalist akademik tədris platformasıdır.

Bu platforma məşhur **Engnovate** platforması ilə tam sinxron və yanaşı (**Companion Mode**) işləmək üçün optimallaşdırılmışdır:
* Engnovate-dəki sessiya keşlənməsi və limit xəbərdarlıqlarının yaratdığı çaşqınlığı aradan qaldırır.
* Sualları, vaxt taymerlərini, C1/C2 lüğətlərini və Band 8.5 model cavablarını bir pəncərədə təmiz şəkildə təqdim edir.

## ⚡ Əsas İnteraktiv İmkanlar və Modullar

1. ⏱️ **Speaking Part 2 Taymerləri və Səsli Xəbərdarlıq:**
   - 1 dəqiqəlik hazırlıq və 2 dəqiqəlik danışıq taymerləri.
   - İnternetsiz işləyən Web Audio API Chime xəbərdarlıq siqnalı.
   - Hazırlıq vaxtı açar sözləri qeyd etmək üçün LocalStorage ilə avtomatik yadda saxlayan **Scratchpad**.
2. 🎙️ **Daxili Audio Recorder:**
   - Danışığınızı birbaşa brauzerdə yazma, dərhal dinləmə və `.webm` formatında kompüterə yükləmə imkanı.
3. 🇦🇿 **Band 8.5 Model Cavablar və Azərbaycan Dilində İzahlar:**
   - Cambridge 21 Academic Speaking Test 3-ün bütün suallarına (Part 1, 2, 3) C1/C2 səviyyəli nümunəvi cavablar.
   - Tək kliklə açılan Azərbaycanca Tərcümə akordionu və interaktiv söz çipləri.
4. 💎 **Lexical Resource Vault (C1 / C2):**
   - İmtahanda yüksək bal qazandıran akademik kollokasiyalar və idiomlar.
   - Canlı axtarış və kateqoriya üzrə filtrləmə.
5. ✍️ **Academic Writing Blueprints:**
   - Task 1 və Task 2 üçün akademik strukturlar, giriş/overview şablonları və bağlayıcı ifadələr (*cohesive devices*).
6. 🖥️ **Engnovate Companion (Sidecar Mode):**
   - Saytı tək kliklə dar yan panel rejiminə keçirərək Engnovate ilə paralel işləmə imkanı.
7. 📖 **500 İngilis Sözü 25 Hekayədə (Bilingual Reader):**
   - Hərəsində 20 hədəf söz olan 25 hekayə, paralel Azərbaycan dilində tərcümə, səsli tələffüz və aktiv yaddaş ("Test Rejimi") cədvəli.

## 💡 Engnovate ilə Keşsiz və Limitsiz İşləmə Bələdçisi

Engnovate platformasında test işləyərkən limit və ya upgrade xəbərdarlıqları ilə qarşılaşmamaq və hesabları rahat dəyişmək üçün:
1. **Google Chrome Incognito (Gizli Pəncərə — `Cmd + Shift + N`):**
   Engnovate-i hər zaman Gizli Pəncərədə açın. Tapşırığı bitirib pəncərəni bağladıqda bütün sessiya çərəzləri və keş avtomatik silinir.
2. **Materialları bu platformadan izləyin:**
   Sualları, taymerləri və lüğət bazasını **[suleimanielts.github.io](https://suleimanielts.github.io)** platformasından izləyib, Engnovate-dən sadəcə cavabları yoxlamaq üçün istifadə edin.
